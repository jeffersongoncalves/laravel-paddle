# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-09-08

Initial release.

- Products, prices, customers, subscriptions, transactions, discounts, adjustments, events and notifications resources for the Paddle Billing API v1
- `Paddle-Signature` webhook verification (HMAC-SHA256 with a replay window)
- Sandbox support via `PADDLE_SANDBOX`
- `PaddleException` exposing Paddle's error body and machine-readable error code
- Laravel 12 / 13, PHP 8.2+
